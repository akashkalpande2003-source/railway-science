# 🚆 Railway Science

**Railway Science** एक Railway Exam-focused Science learning website है, जो Class 9 और Class 10 Science को Railway exams की तैयारी के लिए आसान तरीके से उपलब्ध कराता है।

🌐 **Live Website:**  
https://akashkalpande2003-source.github.io/railway-science/

---

## 📚 Features

- 📖 Class 9 Science Notes
- 📖 Class 10 Science Notes
- 🚆 Railway Exam-oriented Science Content
- 📝 Railway PYQ / Practice Questions
- 🎯 Group D Style Mock Tests
- ✅ MCQ-based Tests
- 📊 Test Result & Score
- ❌ 1/3 Negative Marking
- 📘 Question-wise Detailed Solutions
- 📱 Mobile Friendly Design
- 🇮🇳 Hindi Medium Study Material

## 📝 Mock Test System

Website में Railway exam pattern को ध्यान में रखते हुए mock tests बनाए गए हैं।

### Test Features

- Multiple Choice Questions
- Question Palette
- Previous / Next Navigation
- Mark for Review
- 20 Minute Timer
- 1/3 Negative Marking
- Automatic Score Calculation
- Correct / Wrong / Not Attempted Count
- Submit के बाद Detailed Solutions
